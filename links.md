## Software I Use

### Version control
- [darcs](https://darcs.net/) — patch-based version control.
- [git](https://git-scm.com/) — the version control system everything else talks to.
- [jujutsu](https://github.com/jj-vcs/jj) — a git-compatible VCS with a simpler model for rewriting history.
- [tig](https://jonas.github.io/tig/) — a text-mode interface for browsing git history.

### Editors
- [gg](https://github.com/gmgreenfield/gg) — my own minimal screen editor.
- [neovim](https://neovim.io/) — a modernized, extensible fork of Vim.
- [vim-classic](https://vim-classic.org/) — Vim kept close to its traditional form.

### Desktop
- [dmenu](https://tools.suckless.org/dmenu/) — a fast, minimal launcher and menu for X.
- [dwm](https://dwm.suckless.org/) — a small, keyboard-driven tiling window manager.
- [st](https://st.suckless.org/) — the simple terminal from suckless.
- [surf](https://surf.suckless.org/) — a minimal WebKit-based browser.

### Shell & mail
- [alpine](https://alpineapp.email/) — a terminal email client.
- [zsh](https://www.zsh.org/) — my interactive shell.

### Security & networking
- [sequoia-pgp](https://sequoia-pgp.org/) — a modern OpenPGP implementation.
- [vaultwarden](https://github.com/dani-garcia/vaultwarden) — a lightweight, self-hostable Bitwarden-compatible password server.
- [wireguard](https://www.wireguard.com/) — a simple, fast VPN.
- [zerotier](https://www.zerotier.com/) — virtual networks that connect machines across locations.

### Browser extensions
- [OneTab](https://www.one-tab.com/) — collapses open tabs into a list.
- [Textarea Cache](https://github.com/wildskyf/TextareaCache) — saves what you type in text boxes so it isn't lost.
