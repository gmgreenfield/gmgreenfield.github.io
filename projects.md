Projects pinned on [my GitHub profile](https://github.com/gmgreenfield).

- [dwm-improved](https://github.com/gmgreenfield/dwm-improved) — The DWM project from Suckless with my own customizations and a select group of patches applied to improve usability.
- [gg](https://github.com/gmgreenfield/gg) — A programmer's screen editor written for Posix compliant operating systems; similar feature wise to Atto. Automated tests written for Linux and Mac OS.
- [st-improved](https://github.com/gmgreenfield/st-improved) — The suckless terminal project with my own customizations and patch set. Meant to be used with my customized DWM.
- [slackware-linux-1.2.0-march-1994](https://github.com/gmgreenfield/slackware-linux-1.2.0-march-1994) — An archival, self-contained Linux system from 1994: vanilla Linux 1.0 with a Slackware 1.2.0 userland, booting from an IDE disk through SeaBIOS and ported LILO.
- [mac-url-clip-statusbar](https://github.com/gmgreenfield/mac-urlclip-statusbar) — A native macOS status bar app that watches the clipboard for URLs and other configured regex matches, then saves them locally in a sqlite database. A similar project is available here for Linux that runs as a daemon.
