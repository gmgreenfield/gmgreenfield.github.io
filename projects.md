A selection of my projects. More are on [my GitHub profile](https://github.com/gmgreenfield).

## Editors & Terminal Tools

- [gg](https://github.com/gmgreenfield/gg) (C) — A programmer's screen editor written for POSIX-compliant operating systems; similar feature-wise to [atto](https://man.netbsd.org/atto.1). Automated tests written for Linux and macOS.
- [ggpage](https://github.com/gmgreenfield/ggpage) (Rust) — A terminal pager for SQL client output and a drop-in replacement for `less`. It parses mysql/MariaDB, psql, sqlite3 and mycli output into a real grid with a pinned header, frozen columns, horizontal scrolling and search.

## macOS Apps

- [GopherPath](https://github.com/gmgreenfield/GopherPath) (Objective-C) — A native macOS Gopher client written with AppKit.
- [mac-urlclip-statusbar](https://github.com/gmgreenfield/mac-urlclip-statusbar) (Swift) — A native macOS status bar app that watches the clipboard for URLs and other configured regex matches, then saves them locally in a SQLite database. A similar project, [url-clipboard-tracker](https://github.com/gmgreenfield/url-clipboard-tracker) (Python), runs as a daemon on Linux.

## Retro Computing

- [slackware-linux-1.2.0-march-1994](https://github.com/gmgreenfield/slackware-linux-1.2.0-march-1994) (C) — An archival, self-contained Linux system from 1994: vanilla Linux 1.0 with a Slackware 1.2.0 userland, booting from an IDE disk through SeaBIOS and ported LILO.
