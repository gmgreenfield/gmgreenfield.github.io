--- layout: page title: "About" --- Hey, I'm Graham Greenfield. This site is a collection of notes, ideas, and writing about software development. When I want to understand a concept more deeply, work through an idea, or spend some time to better understand how something works I write about it. My main interests these days are systems programming, BSD and GNU/Linux, cryptography, and LLMs, including their tuning and practical application. For the first ~12 years of my software engineering career I did a lot of backend development and web services. These days I'm focusing more on systems, infrastructure, and lower level tooling. I'm also interested in how LLMs fit into the software development process. I mean they can be genuinely useful tools: an interactive meta documentation browser, a way to explore an idea, a means to work around language limitations, etc. If an LLM helped a programmer write something, hey no problem. But when the person responsible for the code can't easily explain what it does, why it's there, or why it's written that way there's a real problem. It's negligent to put code in production that you don't understand, period. I'm not trying to make myself out as a saint, but I know enough to see where this is heading. It's why tools like Claude or Codex that can take a request, write the files, and immediately give you a working solution by leveraging training data from open source projects—all without feedback from the programmer—are so dangerous. I'm not currently looking for a new job. I'm happy doing more systems-oriented development these days, and I'm enjoying where that's taking me. The way I see it, there's value staying some amount of hands-on, and I'm trying to make sure that I do that.
