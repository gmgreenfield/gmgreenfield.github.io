Hey, I’m Graham Greenfield. This site is a collection of notes, ideas, and writing about software development. When I want to understand a concept more deeply, work through an idea, or spend some time thinking about a problem, I tend to write a blog post about it.

My main interests these days are systems programming, BSD and GNU/Linux, cryptography, and LLMs, including their tuning and practical application. For the first ~12 years of my software engineering career, I primarily worked in web development, using Python, PHP, JavaScript, and even a bit of J2EE. At this point, I’ve spent enough time making CRUD type web apps where I’m happy to leave that work behind.

I’m also interested in how LLMs fit into the software development process. I mean they can be genuinely useful tools: an interactive meta documentation browser, a way to explore an idea, a means of thinking through a design, or potentially another way to see a problem. However, I want to make a distinction between using a tool to help you think and using it instead of thinking.

I’m not currently looking for a new job. I’m happy doing more systems-oriented development these days, and I’m enjoying where that’s taking me.
